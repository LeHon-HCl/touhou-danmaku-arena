# 音频素材（audio）

把音频放进这个目录即可生效，**文件名必须与下表完全一致**。

- 优先格式：**`.ogg`**（体积小、浏览器支持好）；也可以放 `.mp3`，两者同名时优先 `.ogg`
- ⚠️ **不要用 `.wav` 作为成品格式**：仓库的 `.gitignore` 忽略了 `*.wav`（那是混音母带的规则），放进去不会进版本库
- 采样率 44.1kHz 或 48kHz，单声道即可（立体声定位由程序按声源位置实时计算）
- 缺失的文件不会报错，会自动回退到程序合成的占位音

| 文件名             | 用途       | 建议时长   | 音量参考             |
| ------------------ | ---------- | ---------- | -------------------- |
| `shoot.ogg`        | 开枪       | 0.06–0.12s | 中偏小，会被高频触发 |
| `hit.ogg`          | 子弹命中   | 0.05–0.10s | 中                   |
| `shield_break.ogg` | 护盾破碎   | 0.15–0.30s | 中偏大               |
| `death.ogg`        | 角色被击倒 | 0.25–0.50s | 大                   |
| `hurt.ogg`         | 自己受伤   | 0.10–0.20s | 大                   |
| `pickup.ogg`       | 拾取道具   | 0.10–0.20s | 中                   |

> 相对音量已经写在 `client/src/audio/audio-manager.ts` 的 `BASE_VOLUME` 里，
> 建议**先把音频本身归一化到同一响度**，再靠这张表微调，否则换素材会忽大忽小。

详细说明与改音流程见 [../README.md](../README.md)。
