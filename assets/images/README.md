# 图片素材（images）

把 PNG 放进这个目录即可生效，**文件名必须与下表完全一致**（全小写、下划线分隔）。

- 格式：**PNG** 最佳（带透明通道）；`.jpg` / `.jpeg` / `.webp` / `.avif` / `.gif` / `.bmp` 也认，但没有透明通道会带一块方形背景
- 尺寸：与下表不同时会自动**等比缩放并居中**到目标尺寸，控制台会给出警告；省事的话直接按表里的尺寸导出
- 像素风：直接用目标尺寸绘制，**不要**放大后再缩小，也不要加抗锯齿
- 缺失的文件不会报错，会自动回退到程序画的占位图

| 文件名                   | 尺寸  | 用途                                      |
| ------------------------ | ----- | ----------------------------------------- |
| `char_reimu.png`         | 48×48 | 博丽灵梦（正面视角，左右翻转表示朝向）    |
| `char_marisa.png`        | 48×48 | 雾雨魔理沙                                |
| `char_dummy.png`         | 48×48 | 练习场假人靶                              |
| `bullet_player.png`      | 12×12 | 玩家子弹                                  |
| `tile_floor.png`         | 32×32 | 地面瓦片（可平铺）                        |
| `tile_wall.png`          | 32×32 | 墙体瓦片（可平铺）                        |
| `fx_particle.png`        | 4×4   | 粒子（命中火花、枪口闪光，会被染色/缩放） |
| `item_heal.png`          | 24×24 | 道具：治疗包                              |
| `item_armorHarden.png`   | 24×24 | 道具：防御强化                            |
| `item_attackBoost.png`   | 24×24 | 道具：攻击强化                            |
| `item_fireRateBoost.png` | 24×24 | 道具：射速强化                            |
| `item_speedBoost.png`    | 24×24 | 道具：移速强化                            |

> 角色四周请至少留 2px 空白：敌我辨识的红色描边由渲染器画在贴图**外侧**，贴边会被裁掉。

详细说明与改图流程见 [../README.md](../README.md)。
